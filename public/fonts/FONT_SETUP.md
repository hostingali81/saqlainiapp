# Font Setup for Hindi PDF Support

## Download Noto Sans Devanagari Font

1. Visit: https://fonts.google.com/noto/specimen/Noto+Sans+Devanagari
2. Click "Download family" button
3. Extract the ZIP file
4. Copy these files to this folder (`public/fonts/`):
   - `NotoSansDevanagari-Regular.ttf`
   - `NotoSansDevanagari-Bold.ttf`

## Alternative Direct Download
Download from: https://github.com/notofonts/devanagari/raw/main/fonts/NotoSansDevanagari/hinted/ttf/NotoSansDevanagari-Regular.ttf

## Required Files
- NotoSansDevanagari-Regular.ttf
- NotoSansDevanagari-Bold.ttf

Place both files in this `public/fonts/` directory.
